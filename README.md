# Psychologists Service App

## Find the right psychologist for you

## 📝 Project Description

A modern web application for browsing psychologists, viewing their profiles, and
booking appointments.

Users can explore specialists, read reviews, add psychologists to favorites, and
schedule consultations.

## 🚀 Technologies Used

- Vite
- React
- Redux Toolkit (state management)
- React Router
- Axios
- CSS Modules

## 📄 Pages Overview

- **Homepage** – contains a promotional banner and a call-to-action section
- **PsychologistsPage** – displays a list of available psychologists with
  sorting options (A-Z, Price, Popular)
- **FavoritesPage** – shows psychologists saved by the user. Users can remove
  items from the list or open their detailed profile

## 🧭 Routing

- / – Homepage
- /psychologists – Psychologists catalog
- /favorites – Favorite psychologists

## 🧠 State Management

The global state is managed with **Redux** and includes:

- psychologists list
- active filters

## ⚙️ Features

- Browse a catalog of psychologists
- Sort psychologists by rating or price
- View detailed information and reviews
- Add psychologists to **Favorites**
- Book an appointment through a form
- User authentication (login / registration)
- Protected routes for authorized users
- Responsive design for desktop, tablet, and mobile devices
- Toast notifications for user feedback

## 🌐 Deployment

The project is deployed using **Vercel**.
